---

Click **Click**, the number goes up. Click **Reset**, it goes back to zero. Leave, come back tomorrow — thanks to Lyra, it's exactly where you left it. That's the whole game, and it exists mostly as an excuse to show **roblox-ts**, **React**, **Lyra**, **Flamework**, and **UI Labs** working together in a real (if tiny) project.

## Previewing the UI

Rather than launching the whole game to tweak a button, this project ships a [UI Labs](https://ui-labs.luau.page/) story that previews the interface on its own, with controls for poking at different states live.
